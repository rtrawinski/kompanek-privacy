# kompanek-privacy

Public static site: the privacy policy (and, later, a support page) for the
[Kompanek](https://github.com/rtrawinski/kompanek) app.

This repo is deliberately separate from and public, while the app's own
source stays private - GitHub Pages requires a public repo on the free plan,
and this keeps the app's source code out of that requirement entirely.

Served via GitHub Pages from this repo's default branch.
